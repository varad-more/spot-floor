{% endif %} {% if aws_present %}

AWS availability is unknown, and that is the honest answer. AWS does not publish spot availability. The nearest thing, Spot Placement Score, is computed against the calling account's quota and history — so a score fetched with this app's credentials describes this account, not your odds of getting capacity. spotfloor does not call that API under app credentials and reports unknown rather than inventing a number.

Vast.ai publishes real per-machine inventory, so its availability column is a fact. That asymmetry is a property of the providers, not a gap in this page.

  • “Cheapest observed”, never “cheapest that exists.” Vast's search API returns a server-side slice, so this is the floor across what we actually saw.
  • GPU models are compared across providers; regions are not. A chip is a chip, so an AWS H100_SXM_80GB and a Vast one are the same silicon at comparable prices. A datacenter is not fungible: Vast's “Japan, JP” is not us-east-1a, and no mapping between them is invented. AWS regions are comparable to each other.
  • Gaps in a sparkline are gaps. A bucket with no observation is drawn as a break, not interpolated — not observed is a different claim from unavailable.
  • Prices are per node ($/hr); the comparison axis is per GPU ($/GPU·hr). JSON: {% if snapshot %}api/market.json, api/history/{gpu_model}.json{% else %}/api/market, /api/history/{gpu_model}{% endif %}.
