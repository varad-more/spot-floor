Why availability is unknown, and what “price moves” measures

AWS does not publish spot availability. The nearest thing, Spot Placement Score, is computed against the calling account's quota and history — so a score fetched with this app's credentials describes that account, not your odds of getting capacity. spotfloor does not call that API and reports unknown rather than inventing a number. This is a price comparator; it does not claim to know what you can get.

“Price moves” is not availability either. It counts how many times the price changed in the window — a real fact from AWS's published history and a fair hint that a zone is contended. It is not a fulfillment probability.

  1. Give AWS read-only permissions. Create an IAM user with the four read-only actions in docs/iam-policy.json. All four are free and none of them can launch, modify or spend anything.
  2. Point boto3 at the key — however you normally would: 
    aws configure                       # writes ~/.aws/credentials
aws sso login --profile my-profile  # then: export AWS_PROFILE=my-profile
    Run aws configure yourself. Never paste keys into files in this repository.
  3. Check it worked, then restart this server: 
    uv run python scripts/check_setup.py
    It tests each piece separately — credentials resolve, credentials are valid, each IAM action, a real live price — and names the exact fix for whatever fails. It never prints secret material.

The full walkthrough is in the README, under Quick start and AWS permissions.

  • A region row names its zone. AWS prices spot per availability zone, and zones inside one region differ — sometimes by 350%. The price shown is the cheapest zone; AZ spread states how much the roll-up hid.
  • Gaps stay gaps. A bucket with no observation is a break in the line, never zero and never the previous price carried forward — not observed is a different claim from unavailable.
  • Spot only (Linux/UNIX), per instance, per hour. Watchlist is {{ config.instance_types | length }} types — bounded on purpose, because us-east-1 alone lists 1,354.
